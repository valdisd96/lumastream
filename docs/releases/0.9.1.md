# LumaStream 0.9.1 — Keep downloading while you watch

Enabled prefetch now downloads ahead during playback, buffering and pause, within your selected disk-cache budget. Android 9+, one universal APK for TV, phones and tablets. **Preview release.**

## Highlights

- **Play no longer stops prefetch.** The optional setting is now named **Continuous prefetch**. Previously saved On/Off preferences are retained.
- **Bounded disk use.** Downloading waits when the cache is full and refills after playback reclaims space. Required video reads keep priority over speculative downloads.
- **Same setup, no new accounts.** Direct torrent input and optional catalog/subtitle integrations are unchanged. In Settings, enable Continuous prefetch and select **Save settings** below the language preferences.

## Download and update

**[Download the APK](https://github.com/valdisd96/lumastream/releases/download/v0.9.1/lumastream-0.9.1-universal.apk)** · [SHA256SUMS](https://github.com/valdisd96/lumastream/releases/download/v0.9.1/SHA256SUMS)

1. Download the APK and checksum file; run `shasum -a 256 -c SHA256SUMS` on macOS or `sha256sum -c SHA256SUMS` on Linux.
2. Install over your previous signed LumaStream release **without uninstalling**, preserving settings and history. With ADB: `adb -s DEVICE install -r lumastream-0.9.1-universal.apk`.
3. Version 0.9.1 uses version code 12 and the existing release certificate. Debug builds use a different key; uninstalling deletes local data and is not a routine upgrade step.

## Verification and limits

Release build, all **162 release JVM tests**, release lint, signature verification, four-ABI native packaging and 16 KB alignment checks passed. A decompressed APK-entry scan found no owner's private TMDB/OpenSubtitles credentials.

Development playback on an ARM64 phone emulator showed 111.5 MiB ahead of the reader at 01:00 while downloading at 3.4 MiB/s, with 129.4 MiB cache usage under the selected 1 GiB limit. Pause/resume and normal native shutdown were exercised. This run did not fill the 1 GiB cache; no new audible-output verification is claimed. See the [maintainer guide](https://github.com/valdisd96/lumastream/blob/main/docs/maintainer-guide.md#storage-and-playback-boundaries) for dated evidence and prior bounded-cache verification.

The published signed APK was installed over 0.9.0 on the physical WK03K projector without uninstalling. Package identity and the enabled prefetch/4 GiB preference were retained; the pulled installed APK matched the release checksum. Actual playing Sintel grew its forward reserve from 13.7 MiB at 00:17 to 22.0 MiB at 00:32, while still downloading at 882 KiB/s. Pause/resume and normal session shutdown passed. Full-cache rollover and audible output were not reverified.

The cache remains temporary: leaving the app stops downloads and removes it. Background downloads, offline saving and picture-in-picture remain unsupported. Peer availability and device codecs still matter. BitTorrent may upload to peers and exposes your network IP; only obtain and share content you are authorized to use.
