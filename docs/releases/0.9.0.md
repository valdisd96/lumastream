# LumaStream 0.9.0 — Start watching without an account

Open your own torrent sources without registering for catalog or subtitle services. One universal APK supports Android TV, phones and tablets on Android 9 or later. This is a **preview release**.

## Highlights

- **Start directly from Home.** Open a magnet link, an HTTPS torrent URL or a `.torrent` document, then choose the video. A system document picker is needed for file selection; links remain available on TVs without one.
- **Choose your integrations.** TMDB and online OpenSubtitles search start Off on a new installation. Enable them in Settings only if wanted and configured. Embedded subtitles, matching torrent subtitles and manual SRT/WebVTT imports need no account.
- **Keep your existing setup.** Upgrades retain previously configured integrations. Turning a service Off keeps its credentials for later but stops requests to it, including TMDB artwork. Saved titles remain readable, and history can resume its cached source without refreshing TMDB.

## Download and install

**[Download the APK](https://github.com/valdisd96/lumastream/releases/download/v0.9.0/lumastream-0.9.0-universal.apk)** · [SHA256SUMS](https://github.com/valdisd96/lumastream/releases/download/v0.9.0/SHA256SUMS)

1. Download the APK and checksum file. Verify with `shasum -a 256 -c SHA256SUMS` on macOS, or `sha256sum -c SHA256SUMS` on Linux.
2. Install it on the device. With ADB: `adb -s DEVICE install -r lumastream-0.9.0-universal.apk`.
3. Select **Open magnet / torrent** on Home. No key is required for this path.

**Optional catalog:** select **Settings → Catalog: TMDB**, enter your API Read Access Token from [TMDB API settings](https://www.themoviedb.org/settings/api), and Save settings. Online OpenSubtitles requires separate compliant application-provider setup, not mandatory registration by every viewer.

**Updating?** Install over an earlier signed release **without uninstalling** to preserve settings and history. Version 0.9.0 uses version code 11 and the existing release certificate. Debug builds use another signing key; uninstalling them deletes their data and is not a routine upgrade step.

## Verification and limits

Release build, all **162 release JVM tests**, release lint, signature verification, four-ABI native packaging and 16 KB alignment checks passed. The APK is non-debuggable and was scanned for the owner's private credentials.

The signed APK was installed over **0.8.0 on the physical WK03K projector** without uninstalling. Package identity, original installation time and visible history were retained; the configured catalog remained available. The installed APK checksum matched this release. Device interaction stopped when other content appeared; no new projector playback or audible-output verification is claimed.

Development checks on an ARM64 phone emulator exercised credential-free playback, torrent document selection, local subtitle controls, saved metadata snapshots and history resume with services disabled. A Google TV emulator exercised D-pad input and keyboard dismissal; its URL playback attempt was blocked by DNS resolution, not counted as playback verification.

Physical phone/tablet playback, x86 runtime and new audible-output verification are not claimed. Subtitle/source availability, codecs and filesystem support depend on the device and providers. See the [maintainer guide](https://github.com/valdisd96/lumastream/blob/main/docs/maintainer-guide.md) for dated evidence and limitations.

BitTorrent may upload to peers and exposes your network IP. Only obtain and share content you are authorized to use. Background playback, background downloads and picture-in-picture remain unsupported.
