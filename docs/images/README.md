# Screenshot credits

These are real LumaStream captures from the 0.8.0 verification sessions on 2026-10-26, not mockups. They were resized proportionally and converted to WebP for the documentation; UI elements and video content were not added or retouched. Original device captures remain local and are not published with logs, device addresses or credentials.

| Image | What it shows | Capture environment |
| --- | --- | --- |
| [TV details](tv-details.webp) | Sintel artwork, title details and Watch later action | ARM64 Google TV emulator, adaptive UI development verification |
| [TV playback](tv-playback.webp) | Sintel paused at 00:12 with 6.6 MiB of 123.3 MiB downloaded | XGIMI MoGo 4 Laser, Android TV 11; published signed 0.8.0 APK |

| [Tablet discovery](tablet-discover.webp) | Top-rated Action collection in portrait | ARM64 tablet emulator, adaptive UI development verification |

A screenshot of a rendered frame is not evidence of audible output or compatibility with every source. Phone/tablet captures are emulator screenshots, not physical-device certification. See the [verification record](../maintainer-guide.md#adaptive-android-verification-080) for the scenarios and limits.
