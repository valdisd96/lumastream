# LumaStream

Android TV-приложение для поиска торрент-раздач и воспроизведения видео до завершения загрузки, в одном APK и без обязательного внешнего сервера.

## Статус

Проект находится на этапе подготовки. Исходного кода приложения и APK пока нет; команды сборки и установки появятся вместе с проверенной реализацией.

## Целевое устройство

Первое устройство — XGIMI MoGo 4 Laser (WK03K):

- Android TV 11, API 30.
- ABI приложений: `armeabi-v7a` (32-битный ARM).
- Доступная ОС оперативная память: около 1,65 ГиБ.
- Основной сценарий: 1080p, встроенные динамики, кэш на внутреннем накопителе.
- Управление пультом, без обязательной мыши или телефона.

ABI и память проверены через ADB. Поддержка конкретных кодеков и воспроизведение через торрент ещё не проверены.

## Техническое направление

- Kotlin и Jetpack Compose for TV — приложение и интерфейс.
- AndroidX Media3 / ExoPlayer — воспроизведение.
- libtorrent-rasterbar через JNI — встроенный торрент-движок. Android-обёртка и версии зависимостей ещё не выбраны; обязательна поддержка `armeabi-v7a`.
- OkHttp — сетевые запросы; Room и DataStore — история и настройки по мере появления соответствующих функций.

Движок должен приоритизировать части, необходимые плееру, включая произвольное чтение и перемотку. Простого открытия недокачанного файла недостаточно. Способ интеграции с Media3 будет выбран при проверке воспроизведения.

## Планируемое поведение

- Поиск по нескольким источникам с допустимым программным доступом, объединение результатов по infohash, отображение ошибок отдельных источников.
- Конкретные каталоги будут выбраны после проверки доступности, API и условий использования. Полный поиск по всем торрентам не обещается.
- Открытие magnet-ссылок и локальных `.torrent` независимо от поиска.
- Выбор раздачи и видеофайла, буферизация, перемотка, аудиодорожки и субтитры.
- Ограниченный дисковый кэш с очисткой и резервом свободного места. Предложенный начальный лимит — 4 ГиБ, не ограничение размера видео. Для больших файлов потребуется освобождение уже просмотренных частей с повторной загрузкой при перемотке назад.

Первый технический этап: на реальном проекторе открыть легально распространяемое тестовое видео через встроенный движок, начать просмотр до полной загрузки, перемотать в незагруженный участок и проверить звук. Затем — поиск и полноценный TV-интерфейс.

## Разработка

Задачи выполняются в отдельных ветках; изменения кода и документации проходят через PR в `main`. Исключение — единственный пустой начальный коммит для создания базовой ветки.

В PR указываются изменения, реально выполненные проверки и известные ограничения. Документация обновляется вместе с каждой реализованной задачей. Тесты добавляются для значимых сценариев и ошибок, без формального наращивания покрытия. Проверка воспроизведения на устройстве не заменяется unit-тестами.

Не публикуйте ключи подписи, токены, личные идентификаторы устройства или локальные сетевые адреса. ADB используйте только в доверенной локальной сети, без проброса порта в интернет.

## Правовые и сетевые ограничения

Используйте только контент, на получение и распространение которого у вас есть разрешение. BitTorrent может раздавать скачанные данные другим участникам; участники видят сетевой IP. Скорость просмотра зависит от доступности частей и скорости раздачи; приложение не гарантирует непрерывное воспроизведение.
