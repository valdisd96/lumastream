# LumaStream 0.8.0 — From the TV remote to your touchscreen

One APK now brings LumaStream to **TVs, phones and tablets** on Android 9 or later. This is a **preview release**; compatibility still depends on your device and chosen source.

## Highlights

- **Browse comfortably on any screen.** Search, discovery, Watch later, History and source selection adapt to touch, narrow windows and portrait or landscape layouts.
- **Rotate without restarting playback.** Touch playback controls and scrollable subtitle dialogs join the existing TV remote controls; rotation keeps the player and torrent session running.
- **Keep your place on TV.** Improved focused rows and initial result visibility make remote navigation clearer, while returning to results restores your saved viewport.
- **One download for supported architectures.** The APK includes ARMv7, ARM64, x86 and x86-64 libraries, with 16 KB page support for the 64-bit libraries. Bundling an architecture does not mean playback has been verified on every device.

## Download and install

**[Download the Android APK](https://github.com/valdisd96/lumastream/releases/download/v0.8.0/lumastream-0.8.0-universal.apk)** · [SHA256SUMS](https://github.com/valdisd96/lumastream/releases/download/v0.8.0/SHA256SUMS) · [Preview release page](https://github.com/valdisd96/lumastream/releases/tag/v0.8.0)

1. Download the APK and checksum file into the same folder. On macOS, verify them with `shasum -a 256 -c SHA256SUMS` (Linux: `sha256sum -c SHA256SUMS`).
2. Transfer the APK to your Android device, allow installation from your chosen installer when Android asks, and open it. With ADB, use `adb -s DEVICE install -r lumastream-0.8.0-universal.apk`.
3. Open **Settings** and save your personal **TMDB API Read Access Token**, available in [TMDB API account settings](https://www.themoviedb.org/settings/api). Use the read access token, not the shorter API key. No credentials or media are bundled.

**Updating an earlier signed preview?** Install over it **without uninstalling** to retain settings and history. Version 0.8.0 keeps the release signing certificate and uses version code 10.

**Coming from a debug build?** Its signing key is different, so this release cannot replace it in place. Uninstalling the debug app deletes its settings and watch history. Do not uninstall unless you accept that loss.

## What was checked—and what was not

- ARM64 **phone emulator with actual 16 KB pages**: playback before the full download, rotation, touch controls, seeking, normal shutdown and cache cleanup.
- ARM64 **tablet emulator**: the signed 0.7.0 → 0.8.0 update retained app identity and a saved preference; the final signed APK rendered advancing video and stopped normally.
- **Google TV emulator**: D-pad focus, search and result-position restoration.
- **Physical WK03K projector (ARMv7, Android TV 11)**: the published APK updated signed 0.6.0 in place without clearing data; Sintel played before the full download, remote pause/resume and seeking worked, and Back stopped the native session. Audible output and private-cache deletion were not independently measured in that release-mode check.

Builds, 158 release JVM tests, release lint and native packaging/alignment checks passed during release preparation. **Physical phone/tablet playback, x86 runtime and audible output were not verified for this release.** Codec, source availability and filesystem support remain device-dependent. See the [detailed adaptive Android verification record](../maintainer-guide.md#adaptive-android-verification-080) for development evidence and its limits; the projector deployment above is recorded in the [published release](https://github.com/valdisd96/lumastream/releases/tag/v0.8.0).

Picture-in-picture and background playback/downloads are not supported. Leaving the app stops the torrent session.
